# Wedding Za Code Style

The codebase should read like code written and reviewed by a human team.

## Core rules

- Never compress multiple statements onto one line.
- Use clear indentation and vertical spacing.
- Prefer one logical operation per line.
- Keep PHP control flow easy to scan.
- Keep HTML/PHP templates visually nested.
- Keep JavaScript functions expanded and readable.
- Keep CSS with one declaration per line.
- Prefer descriptive names over clever shortcuts.
- Add comments only when they explain intent, constraints, or non-obvious behavior.
- Readability is part of QA, not an optional cleanup step.

## Indentation

- PHP and HTML templates: 4 spaces.
- JavaScript, CSS, JSON and Markdown: 2 spaces.
- Do not use tabs for indentation.

## Pull requests

A feature is not complete if it works but is difficult to read or maintain.
